🦅 Notificador de Editais PNCP - CAE / FAB
Descrição
Sistema de governança desenvolvido para otimizar o fluxo de informações do Centro de Aquisições Específicas (CAE) da Força Aérea Brasileira (FAB). A ferramenta automatiza o acompanhamento e notifica unidades interessadas sobre atualizações e novas publicações de editais de forma ágil e centralizada.

🚀 Funcionalidades

Monitoramento contínuo de editais através do Portal Nacional de Contratações Públicas (API PNCP).

Disparo de notificações automáticas via WhatsApp para os contatos das unidades da FAB.

Interface gráfica nativa para gerenciamento e controle da operação.

Banco de dados local para registro histórico e controle dos editais já processados.

🛠️ Tecnologias Utilizadas

Linguagem: Python

Banco de Dados: SQLite

Integrações: API REST (PNCP) e automação web (WhatsApp)

Distribuição: PyInstaller (Geração de executável autônomo)
